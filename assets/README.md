# We Share Brand Assets & Design System

Official visual identity resources, UI icons, and installer graphic assets for **We Share**.

---

## Directory Overview

```
assets/
└── brand/
    ├── APP LOGO.png          # High-resolution primary application icon (1024x1024)
    ├── full png.png          # Primary brand mark with transparent background
    ├── We Share.png          # Inno Setup wizard banner graphic (164x314)
    ├── installer_banner.bmp  # Windows 24-bit RGB bitmap compiled into installer
    ├── installer_banner.png  # Lossless PNG version of setup wizard graphic
    ├── send.png              # High-speed outbound transfer feature graphic
    ├── receive.png           # Secure inbound payload feature graphic
    ├── find.png              # Zero-config network peer discovery graphic
    ├── profile.png           # User identity and device profile badge
    └── background.png        # Ambient ecosystem background canvas
```

---

## Technical Specifications

| Asset | Dimensions | Format | Usage Context |
| :--- | :--- | :--- | :--- |
| **APP LOGO.png** | 1024 &times; 1024 | PNG (32-bit RGBA) | Application icon, release branding, store assets |
| **full png.png** | 512 &times; 512 | PNG (32-bit RGBA) | Navbars, headers, transparent mark badges |
| **We Share.png** | 164 &times; 314 | PNG (24-bit RGB) | Inno Setup Welcome / Finished page left banner |
| **installer_banner.bmp** | 164 &times; 314 | BMP (24-bit RGB) | Native Windows Installer wizard page backdrop |
| **send.png** | 512 &times; 512 | PNG (32-bit RGBA) | Send workflow UI, marketing documentation |
| **receive.png** | 512 &times; 512 | PNG (32-bit RGBA) | Receive workflow UI, marketing documentation |
| **find.png** | 512 &times; 512 | PNG (32-bit RGBA) | UDP radar & peer discovery dialogs |
| **profile.png** | 512 &times; 512 | PNG (32-bit RGBA) | Settings, peer card avatars |
| **background.png** | 1920 &times; 1080 | PNG (24-bit RGB) | Ambient desktop application and web backdrop |
