File Sharing Guide

Follow these instructions to configure local PC-to-PC transfers, mobile sharing via the web portal, and offline hotspot configuration.

PC to PC PC to Mobile Mobile to PC Offline Hotspot

PC to PC (Local Subnet)

Transfer files between two computers on the same local subnet (Wi-Fi or Ethernet). Devices discover each other automatically.

1

Start We Share on both devices

Download and run the application on both computers. On startup, the utility scans the local subnet using UDP broadcasts and lists active peers on the radar visual.

2

Stage files on the sending PC

On the sending computer, drag and drop files/folders into the application window, or click the staging area to browse and select files.

3

Select the destination peer

Look at the discovery radar visual and click the name of the target computer to select it as the destination peer.

4

Initiate the transfer

Click the Send button. This initiates a TCP connection request to the receiver, triggering a notification on their screen.

5

Accept the transfer on the receiving PC

The receiver must click Accept on the prompt. The file transfer begins immediately over a direct TCP socket connection.

Note: Transfer speeds are limited only by your physical network link (e.g. Wi-Fi router bandwidth or Ethernet cabling).

PC to Mobile (Web Portal)

Access shared files from any phone, tablet, or secondary device using the built-in HTTP dashboard. No app install needed on the client.

1

Open We Share on the host PC

Start the app on your computer. The background HTTP server will automatically run on port 8080.

2

Connect the mobile device to the same Wi-Fi

Ensure that the receiving phone or tablet is connected to the same local Wi-Fi router as the host PC.

3

Retrieve the Web Portal IP address

The host PC's interface displays the local access address. It typically looks like this:

http://192.168.1.104:8080
4

Navigate to the address on your mobile device

Open a web browser on the mobile device and enter the IP address. The web dashboard will load.

5

Select and download files

Browse the files staged for web sharing on the host PC, and click download on the web interface to save them to your mobile storage.

This works on any device running a modern web browser (iOS, Android, macOS, Linux, or iPadOS).

Mobile to PC (Upload via Web Portal)

Send files from your phone or tablet directly to your computer using the local web dashboard.

1

Open the Web Portal address on your mobile browser

Access the portal using the host PC's local IP address (e.g. http://192.168.1.104:8080).

2

Tap the upload button in the browser

Click the Upload button on the mobile dashboard interface. This opens your device's native file/photo selector.

3

Select files and transmit

Select the photos, videos, or documents you want to transfer. The browser will transmit them directly to the PC over the local network.

4

Files are saved to your PC

Uploaded files are written directly into the designated receive directory configured on your computer's We Share client.

Offline Hotspot (Desert Mode)

Transfer files when there is no active local network or Wi-Fi router nearby.

1

Launch We Share on PC A (Host)

When the application detects no active network connection, it automatically initializes a local, secure Wi-Fi hotspot named WeShare.

2

Launch We Share on PC B (Client)

PC B detects the background hotspot and connects to it automatically using native WLAN APIs, without requiring any manual password entry.

3

Proceed with local transfer

Once connected, both computers list each other on their radars and can transfer files directly over the ad-hoc connection.

This flow is fully automated. No local configuration is changed, and the client will reconnect to its previous Wi-Fi network once the app is closed.
