Release Notes

Version history and technical changelogs for the We Share project.

v1.0.0 June 2026 Latest
  • New **Desert Mode with Captive Portal**: Provision local hotspots and automatically route mobile users to the Web Portal via DNS and HTTP port 80 proxy redirects.
  • New **Pre-Upload Authorization**: Mobile uploads are fully verified and approved by the PC host via secure API permission requests *before* the file payload is transmitted.
  • New **Live Speed Graphs & Dialogs**: Real-time canvas-based speed graphs and flat green Windows-style progress bars on the Web Portal, matching the custom-drawn desktop speed line charts.
  • New **Single-Session Enforcement**: Prevents multiple concurrent device transfer sessions, protecting active connections by restricting and blocking page operations to one active peer.
  • New **Local SQLite database history logs**: Track all incoming and outgoing file transfers in a persistent database, with automatic startup migration for stuck transfers.
  • Improve Robust multi-threaded TCP socket transfer engine with live transfer speed calculation and estimated completion times.
  • UI Fluent-design interface powered by Avalonia UI, styled with frosted-glass panel effects and an indigo-slate dark theme.
  • UI **Web Portal Visual Redesign**: Premium typography using loaded Google Fonts (`Bricolage Grotesque` & `Plus Jakarta Sans`), curated zinc/emerald color scheme, zero shadows/glows, and a dynamic scrolling marquee banner.
