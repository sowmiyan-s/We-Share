Release Notes

Version history and technical changelogs for the We Share project.

v1.3.1 June 2026 Latest
  • Fix Resolved mobile file transfer failure when requesting downloaded files from the PC client.
  • UI Completely removed all emojis from the web portal and desktop client application.
  • UI Introduced clean, color-coded file extension pills and client connection shortcodes (e.g. MOB, PC, LNX).
  • UI Styled information cards with flat, technical indicators (SEC and MIT badges).
  • Improve Integrated Cabinet Grotesk and Manrope typography with an obsidian dark theme for the web portal.
Download v1.3.1 →
v1.3.0 May 2026
  • New Transfer Wizard — step-by-step UI workflow for staging and executing file transfers.
  • New Splash screen with vector loading animation during application assembly initialization.
  • New Sweeping radar animation indicating active background UDP discovery scans.
  • Improve Restructured TCP socket handling to use multi-threaded buffering, improving throughput for large files.
  • Improve Peer entries on radar now parse and render NetBIOS hostnames and platform OS icons.
  • Improve Updated progress indicator to render instantaneous network speeds (MB/s) and ETA.
  • UI Frosted-glass panel styles and tuned color weights for better readability.
  • UI Toast indicators now slide downward from the upper margin using native Avalonia transitions.
  • Fix Resolved hotspot provisioning errors by querying and cleaning legacy tethering adapter states on startup.
  • Fix Prevented null reference crashes when invoking transfer prompts while the window is minimized.
  • Fix Resolved content security parsing issues preventing Firefox from loading local Web Portal scripts.
Download v1.3.0 →
v1.2.0 March 2026
  • New Web Portal — built-in HTTP server listening on port 8080 for web-based transfers on non-Windows devices.
  • New Live upload progress indicator inside the mobile web interface.
  • New Redesigned transfer prompt detailing staged files size and payload counts.
  • Improve Optimized UDP broadcast intervals to minimize radar peer discovery latency.
  • Improve Inno Setup script now handles silent upgrade and keeps SQLite database files intact.
  • UI Re-rendered the radar panel with cleaner concentric vector designs.
  • UI Display local IP bindings and web portal address inside the Settings pane.
  • Fix Added socket connection timeouts and handled connection exceptions gracefully when blocked by firewalls.
  • Fix Handled cases where system host machine name lookup returned null.
Download v1.2.0 →
v1.1.0 January 2026
  • New Desert Mode — auto-provisions ad-hoc hotspots and handles background client association.
  • New Local SQLite database integration to archive transfer logs.
  • New Prompts automatically timeout and reject transfers after 30 seconds of receiver inactivity.
  • New Folder directory parsing and batch file stream queueing.
  • Improve Implemented parallel TCP stream chunking for multi-core processors.
  • Improve Setup installer automatically registers Windows Firewall rules using netsh.
  • UI Implemented standardized dark theme styles.
  • Fix Properly disposed connection resources and updated radar states when peer connection drops.
  • Fix Handled system configurations lacking active network adapters.
