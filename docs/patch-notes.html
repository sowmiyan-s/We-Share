What's New

A full history of every We Share release — features added, bugs fixed, and improvements made.

v1.3.0 May 2026 Latest
  • New Transfer Wizard — a guided step-by-step flow for sending files, reducing friction for first-time users
  • New Animated splash screen with orbital ring loader on startup
  • New Radar scan sweep animation now shows active discovery in real time
  • Improve Multi-threaded TCP engine rewritten for better throughput on large files
  • Improve Device nodes on radar now show device name and OS icon
  • Improve Transfer progress bar now shows speed (MB/s) and ETA
  • UI New premium dark theme with Indigo/Slate color palette, frosted glass cards
  • UI Toast notifications slide in from top with smooth animation
  • Fix Desert Mode hotspot no longer fails when Windows Hotspot was previously left in an error state
  • Fix Fixed a rare crash when accepting a transfer while the app was minimized
  • Fix Web Portal no longer shows a blank page on first load in Firefox

v1.2.0 March 2026
  • New Web Portal — any browser-capable device can now send/receive files from the PC at http://<ip>:8080
  • New Web Portal displays a live file upload progress bar in the browser
  • New Accept / Reject notifications redesigned — now show file preview icon and total size
  • Improve UDP discovery broadcast interval reduced for 2× faster device appearance on radar
  • Improve Installer now auto-uninstalls previous version before upgrading, keeping history database intact
  • UI Radar redesigned with concentric rings and pulsing device nodes
  • UI Settings page now shows current local IP and Web Portal URL for easy sharing
  • Fix Fixed transfers failing silently when sender's firewall blocked outbound TCP on port used
  • Fix Fixed device name showing as empty string on some Windows configurations

v1.1.0 January 2026
  • New Desert Mode — auto-creates Wi-Fi hotspot when no router detected; other PC auto-connects with no user input
  • New Transfer history stored in local SQLite database, viewable in the History tab
  • New Accept / Reject popup with 30-second auto-reject timer
  • New Multiple file selection — send entire folders in one go
  • Improve TCP engine now uses parallel streams for large files, doubling throughput on fast networks
  • Improve Installer now adds Windows Firewall rules automatically
  • UI Full dark mode design system implemented across all screens
  • Fix Fixed radar not updating when a device disconnected mid-session
  • Fix Fixed first-run crash on systems without a default network adapter configured
