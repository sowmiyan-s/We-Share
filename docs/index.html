Built for speed and local utility

No arbitrary bandwidth limits, no cloud middle-men, and no account registrations. Your data stays on your local network.

Direct Socket Transfers

Utilizes multi-threaded TCP streams that saturate your local network connection. Transfer large files at the maximum physical speed of your network card—no server throttling.

TCP Sockets

Zero-Config Discovery

Uses simple UDP broadcasts to identify other We Share instances on your local subnet automatically. No need to copy IP addresses or enter pairing codes.

Built-in Web Portal

Allows mobile devices (iOS, Android) on the same network to share files via a web browser at port 8080. No client app install required on the phone.

Explicit Consent

You have full control over what is received. Incoming file transfers require explicit permission before files are written to your local disk.

Local History Database

All transfer events (sender, size, status, and time) are logged to a local, offline SQLite database on your device. Zero remote analytics.

Open Source & Independent

The code is fully open and MIT-licensed. There are no tracking scripts, telemetry calls, or remote servers. You can inspect the source code and compile it yourself.

Simple usage workflow

01

Start the application

Launch We Share on both the sending and receiving computers. They will automatically scan the local network and discover each other.

02

Select files & target

Drag and drop files or folders into the application, select the target device from the radar visual, and click Send.

03

Accept the transfer

The receiving computer receives a prompt. Once accepted, files are sent directly over TCP. No internet connection is used.

Offline Direct Sharing (Desert Mode)

If there is no local network or Wi-Fi router available, We Share can establish a direct connection between computers using native Windows APIs.
